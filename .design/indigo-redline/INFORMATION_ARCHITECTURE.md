The sidebar also keeps the signed-in identity, role, theme switch, profile, and logout visible. Mobile uses the same hierarchy behind a text-labeled menu control.

## Page hierarchy

Each screen follows: context eyebrow → page title → primary/secondary actions → search and filters → summaries or working data → pagination/supporting information. Details follow identity → current status and location → core metadata → operational actions → history or service records.

## Action hierarchy

Primary red actions are limited to the main task. Secondary outlined actions support navigation and import/export. Table rows use explicit text actions. Destructive actions are visually separated and never share primary styling.
